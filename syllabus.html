📊 Python Data Science: Course Syllabus

An instructor-led course in 21 three-hour sessions. Learn to turn raw data into answers you can defend: NumPy, pandas, Matplotlib, statistics, SQL, web data and dashboards, all practiced on one fictional company's data and finished with a capstone report.

📚 Course Description

Data science is a way of working: ask a clear question, get the data, clean it, explore it, test what you think you see, and show what you found. This course teaches the Python tools for each of those steps in the order you would use them on a real project.

Every session uses the same dataset: two years of records from Pinecrest Outfitters, a fictional outdoor-gear retailer with an online shop and four stores. Orders, customers, products, daily store traffic and weather, a customer survey, a checkout-page experiment, a SQLite database, nested website sessions and a deliberately messy export. The web sessions use a practice shop and a practice API built for the course, so your code never points at a real site while you learn.

🎯 By the end you will be able to

  • Compute with arrays in NumPy instead of writing loops
  • Load, clean, reshape, combine and summarize tables with pandas
  • Build clear charts with Matplotlib and seaborn, and interactive ones with Plotly and Bokeh
  • Describe data honestly and run a hypothesis test or an A/B test without fooling yourself
  • Query a database with SQL from Python, including joins, window functions and indexes
  • Collect data from web pages and APIs politely and safely
  • Turn an analysis into a small dashboard, and write up findings in a one-page report

✅ Prerequisites

  • Comfortable writing small Python programs: variables, if, loops, functions, lists and dictionaries, reading and writing files, and basic classes, as taught in Introduction to Programming with Python and Intermediate Python (free at Ray's House of Fun).
  • No statistics or prior data experience is needed.
  • A Windows, macOS or Linux laptop on which you can install software, with about 2 GB free. Setup is done at home before Session 1 (it follows Lesson 0.1).

💡 Format

21 sessions × 3 hours = 63 class hours, two lessons per session (the capstone session has one). Every lesson on the course site is written for a solo learner and takes 75 to 110 minutes, so two lessons do not fit whole in one room session. The room protects what is hardest alone: the mental model, a live-coding demo you type along with, a guided lab with help on hand, and starting each lesson project. At home you finish the two projects and do each lesson's exercises, quiz and journal entry on the free course site: about two to three hours between sessions.

Each session runs 0:00 to 3:00: a warm-up on last session, the first lesson, a 10-minute break, the second lesson, and a wrap-up with an exit ticket and the next bring list.

Twice weekly: about 11 weeks. Two homework sets a week, so plan on four to six hours outside class.
Weekly: 21 weeks, with a full week for each homework set.
Intensive days: two sessions a day; homework becomes evening practice and the capstone is finished afterward.

🏁 Checkpoints and Capstone

  • Self-checks and exit tickets in every session are practice, not grades: they tell you and your instructor what to revisit.
  • Checkpoint 1 (Session 13, 30 minutes): an individual, open-notebook analysis task on Modules 1 to 4 (NumPy, pandas, charts, statistics), scored with a short rubric.
  • Checkpoint 2 (Session 18, 15 minutes): a short data-access task on Modules 5 and 6 (SQL and web data).
  • Capstone: The Pinecrest Report. In Session 20 you choose one of four business questions (why Asheville is falling behind; whether the acquisition channel matters; whether the welcome discount brings people back; what the March 2025 price increase did) and write a one-paragraph plan. Session 21 is a studio with milestone check-ins, then a showcase. You hand in a notebook that reruns from top to bottom, one or two figures, and a one-page report, judged on six criteria: question, data handling, analysis correctness, visuals, communication and reproducibility. An honest, well-supported "no clear difference" scores as well as a dramatic finding.

🧰 Required Software and Data

  • Python 3.12 or newer: with a virtual environment for the course
  • The course packages: one command: python -m pip install -r requirements.txt (NumPy 2.5, pandas 3.0, Matplotlib 3.11, seaborn, SciPy, statsmodels, SQLAlchemy, PyMongo, Requests, Beautiful Soup, Selenium, Plotly, Bokeh, Streamlit)
  • JupyterLab or VS Code: JupyterLab installs with the packages; VS Code needs its Python and Jupyter extensions
  • Google Chrome: Selenium drives it in Session 17; Plotly uses it to save charts as images
  • The course data: pinecrest-data.zip and, for working offline in Sessions 16 to 18, pinecrest-practice-site.zip, both from the course home page
  • No accounts or paid tools: the practice API runs on your own laptop, with demo keys given in class

Everything installs once, at home, before Session 1, following Lesson 0.1. Your instructor sends a setup guide and an environment check a week ahead.
