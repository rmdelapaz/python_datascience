2.1

DataFrames and Series

90 min lesson
By the end you can
  • Describe a Series as a labeled array and a DataFrame as a set of Series that share one index
  • Inspect any table with shape, head(), info(), dtypes and describe(), and read the dtypes pandas reports
  • Select columns with [], rows and cells by label with .loc and by position with .iloc, and filter rows with boolean masks
  • Add and change columns in a way that works under copy-on-write, and explain why chained assignment never does
  • Sort a table and count the values in a column with sort_values() and value_counts()
Key ideas
  • The labeled shelf. A Series is an array of values plus an index of labels (plus a name). A DataFrame is several Series side by side that share one index. Each column keeps its own dtype.
  • Alignment. Arithmetic between two Series matches labels, not positions. A label with no partner gives NaN. Unexpected NaNs? Compare the two indexes.
  • The four-line greeting. df.shape, df.head(), df.info(), df.describe() on every new table before anything else. In info(), a Non-Null Count below the row count means missing values.
  • dtypes. int64 whole numbers, float64 decimals (and any numeric column with gaps), str text, bool, datetime64[us] dates. A date read from a file is str until you convert it. object on a column today usually means mixed types: investigate.
  • Three selection tools. df["col"] is a Series; df[["a", "b"]] is a DataFrame. .loc[rows, cols] uses labels and its slices include the end. .iloc[rows, cols] uses positions and its slices exclude the stop, like NumPy.
  • Masks. A comparison makes a True/False Series; df[mask] keeps the True rows. Combine with &, |, ~ and put every condition in its own parentheses. .sum() of a mask counts, .mean() gives the share. Helpers: .isin([...]), .between(a, b), .str.contains(...), .isna().
  • Changing a table. New column: df["new"] = ... (whole-column arithmetic, no loop). Some rows: df.loc[mask, "col"] = value. If/else: np.where(cond, a, b).
  • Copy-on-write. Every piece you take from a table behaves as an independent copy. So df[mask]["col"] = value (chained assignment) never changes df. It only warns.
  • Sort and count. sort_values("col", ascending=False) returns a new table and the row labels travel with their rows. value_counts() counts categories (missing values left out unless dropna=False); normalize=True gives shares.

2.2

Loading Data

85 min lesson
By the end you can
  • Read a CSV file with the options that matter: columns, dtypes, dates, missing-value markers, separators and header position
  • Read a sheet from an Excel workbook whose header is not on the first row
  • Flatten nested JSON into tables with pd.json_normalize()
  • Process a file in chunks and shrink its memory use with usecols and dtype
  • Write a DataFrame to CSV, Excel, JSON and Parquet, and explain what each format keeps and loses
Key ideas
  • Loading is translation. A text file carries no types. The reader guesses; you brief it with options and then check the result: shape, dtypes, head() after every load.
  • read_csv options that earn their keep. parse_dates=[...] real dates · usecols=[...] only these columns · dtype={...} set a type · index_col · nrows=5 a peek · na_values=[...] extra words for missing · sep=";" · skiprows / header · decimal, thousands · encoding.
  • Three types to set yourself. Dates (they stay str unless parsed). "Int64" (capital I) for whole numbers with gaps: ids, years, counts. "category" for text with few distinct values. Codes with leading zeros (ZIP codes) are text: dtype={"zip": "str"}.
  • Excel. pd.ExcelFile(path).sheet_names lists the sheets. Unnamed columns mean the header is not where pandas looked: skiprows=3 or header=3. To see the top of a sheet as it is: header=None, nrows=8.
  • Nested JSON. json.load the file, find the list of records, pd.json_normalize(records). Inner dictionaries become dotted columns (device.type). A missing key becomes NaN. For a list inside each record: record_path="pages", meta=["session_id"] gives one row per item.
  • Big files. Peek (nrows), load fewer columns (usecols), use smaller dtypes, then chunksize and a running total. Sums and counts combine across chunks; a mean needs a sum and a count; a median cannot be done this way.
  • Writing. Every reader has a writer. to_csv(path, index=False) for people and other tools: it forgets every dtype. to_parquet(path) for your future self: smaller, and dates, categories and Int64 come back as they were.

Brief the reader: the date is a date, and two columns hold only a few distinct values.

ab = pd.read_csv("data/ab_test.csv", parse_dates=["date"],

Check the translation with numbers you can reason about, then save a copy that remembers its types.

print(ab["converted"].sum(), ab["order_value"].notna().sum(), ab["order_value"].isna().sum())
from pathlib import Path
Path("output").mkdir(exist_ok=True)
ab.to_parquet("output/ab_test.parquet")
print(pd.read_parquet("output/ab_test.parquet").equals(ab))

True

The typed table uses far less memory than the plain one, the date has a real minimum and maximum, and the two counts agree: 2,645 visitors converted and exactly 2,645 rows have an order value. The other 25,355 order values are missing because those visitors bought nothing: missing here means 'not applicable', not 'lost'.

Glossary for Session 4

  • Series: a one-dimensional labeled array: values, an index and an optional name.
  • DataFrame: a table: several Series side by side that share one index.
  • Index: the row labels of a Series or DataFrame. The default is RangeIndex: 0, 1, 2, ...
  • dtype: the type of every value in a column: int64, float64, str, bool, datetime64[us], category, Int64.
  • NaN / <NA>: pandas's markers for a missing value. Test for them with .isna(), never with ==.
  • Alignment: matching by label, not by position, when two Series or tables are combined.
  • Boolean mask: a Series of True/False values used to keep the rows where it is True.
  • .loc / .iloc: selection by label (slices include the end) / by integer position (slices exclude the stop).
  • Copy-on-write: the rule that every object derived from another behaves as an independent copy.
  • Chained assignment: df[mask]["col"] = value: two selections and then an assignment. It never changes df.
  • Nullable integer (Int64): a whole-number dtype that can also hold a missing value.
  • Category: a dtype that stores each distinct value once plus a small code per row; good for repetitive text.
  • json_normalize: the pandas function that flattens nested dictionaries into dotted columns; record_path gives one row per item of an inner list.
  • Chunk: one piece of a file read with chunksize, delivered as an ordinary DataFrame.
  • Parquet: a binary, column-by-column file format that stores each column's dtype with the data.
