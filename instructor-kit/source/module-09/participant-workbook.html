3.2

Subplots and Composition

85 min solo
Key ideas
  • Panels on a page. The Figure is the page; each Axes is a panel. The arrangement tells the reader how to read them.
  • plt.subplots(rows, cols) returns an array of Axes: 2-D for a grid, 1-D for one row or column, a single Axes for 1 by 1. squeeze=False always gives 2-D.
  • Loop, don't repeat: for ax, item in zip(axs.flat, items): works for every grid shape.
  • sharey=True makes heights comparable; separate scales show each shape and hide differences in size. Choose for the question, and say so when panels do not share.
  • Label the figure, not four panels: fig.suptitle, fig.supylabel, fig.supxlabel. Use layout="constrained" so nothing collides.
  • plt.subplot_mosaic builds an uneven layout from a picture of names and returns a dictionary: axd["trend"]. A repeated name spans cells.
  • A twin axis with two different measures can be made to say anything. Stack panels with sharex=True, or plot the ratio. A second axis is fine for one quantity in two units (secondary_yaxis).
  • Small multiples: one function that draws a panel on the ax it is given, plus a loop. Gray for the other groups, color for the panel's own.

Worked example: four cities' temperatures as small multiples

Question: how does each store city's year of temperatures compare with the others? Four groups, the same chart for each: small multiples on a shared scale, with the other cities in gray behind each panel. (The lesson draws store revenue; this example uses data/store_weather.csv.)

One row per month, one column per city: the shape that one line per panel wants.

weather = pd.read_csv("data/store_weather.csv", parse_dates=["date"])
weather["month"] = weather["date"].dt.to_period("M").dt.to_timestamp()
highs = weather.pivot_table(index="month", columns="city", values="high_f",
                            aggfunc="mean")
print(highs.round(1).iloc[[0, 6]])
city        Asheville  Bend  Boise  Flagstaff
month                                        
2024-01-01       49.5  37.5   28.5       35.3
2024-07-01       82.4  78.0   95.0       83.3

A function that draws one panel on the Axes it is given, then a loop over a 2 by 2 grid that shares both axes.

def draw_city(ax, table, city):
    for other in table.columns:
        if other != city:
            ax.plot(table.index, table[other], color="lightgray", linewidth=1)
    ax.plot(table.index, table[city], color="#667eea", linewidth=2)
    ax.set_title(city)

fig, axs = plt.subplots(2, 2, figsize=(9, 5), sharex=True, sharey=True,
                        layout="constrained")
for ax, city in zip(axs.flat, highs.columns):
    draw_city(ax, highs, city)
fig.suptitle("Mean daily high by month: each city against the other three")
fig.supylabel("Mean daily high (°F)")
plt.show()
print(axs.shape, [len(ax.lines) for ax in axs.flat])
(2, 2) [4, 4, 4, 4]

Every panel holds four lines, and only one is in color. Because the scale is shared, you can see at once that Boise has the widest swing between winter and summer (its mean monthly high runs from about 28 °F in January 2024 to 95 °F in July 2024) and Asheville the narrowest. With separate scales the four shapes would look almost alike.

3.3

Customizing Plots

90 min solo
Key ideas
  • A default chart is a first draft; you are the editor. Every edit should help the reader get the point faster.
  • The title states the finding; the subtitle says what is plotted, the units and the period. Check the finding with a number before you write it, and keep causes out unless they were tested.
  • Locators choose where ticks go; formatters what they say: "${x:,.0f}", FuncFormatter(thousands), PercentFormatter(xmax=1), mdates.MonthLocator, mdates.DateFormatter("%b %Y").
  • Give color one job: highlight (gray plus one), categories (qualitative, such as Okabe-Ito), magnitude (sequential, such as viridis), above or below a midpoint (diverging, centered).
  • Design for color-blind readers: a safe palette, no red against green as the only difference, and never color as the only cue.
  • Direct labels beat a legend when lines can be labeled at their ends: nothing to look up.
  • Annotate sparingly: ax.annotate with an arrow, ax.axvspan for a period, ax.axhline for a reference. One to three per chart.
  • Delete chart junk (extra spines, tick marks, heavy grids, repeated labels). Bars start at zero. Put repeated choices in a style dictionary and use it with plt.rc_context.

Worked example: one shrinking store, said in five seconds

The finding from Session 7: three stores grew in 2025 and one shrank. A finished chart should say that before anyone reads the axis. (The lesson edits a line chart; this example edits a bar chart.)

The numbers first: revenue growth per store, 2025 against 2024, sorted.

daily = pd.read_csv("data/daily_sales.csv", parse_dates=["date"])
year = daily["date"].dt.year
yearly = daily.groupby(["store", year])["revenue"].sum().unstack()
growth = ((yearly[2025] / yearly[2024] - 1) * 100).sort_values()
print(growth.round(1))
store
Asheville    -5.0
Bend          3.8
Boise         9.3
Flagstaff    19.7
dtype: float64

Horizontal bars, gray plus one accent for the store that shrank, each value written on its bar, a zero line, a finding headline, and the junk removed.

colors = ["#d55e00" if g < 0 else "0.75" for g in growth]
fig, ax = plt.subplots(figsize=(8, 3.4), layout="constrained")
bars = ax.barh(growth.index, growth.values, color=colors)
ax.bar_label(bars, labels=[f"{g:+.1f}%" for g in growth], padding=4)
ax.axvline(0, color="0.3", linewidth=1)
ax.set_title("Asheville is the only store that shrank in 2025", loc="left",
             fontweight="bold", pad=22)
ax.text(0, 1.03, "Revenue change, 2025 against 2024 (register totals)",
        transform=ax.transAxes, color="0.35")
ax.xaxis.set_visible(False)
ax.spines[["top", "right", "bottom"]].set_visible(False)
ax.tick_params(length=0)
ax.set_xlim(growth.min() * 1.6, growth.max() * 1.25)
plt.show()
print([b.get_facecolor()[:3] != (0.75, 0.75, 0.75) for b in bars])
[True, False, False, False]

The printed list marks which bars are not gray: only the first, Asheville. The labels make the x axis unnecessary, so it is hidden; the line at zero is the one reference the reader needs. The headline is a claim the bars prove: -5.0% for Asheville, growth everywhere else.

Glossary

TermMeaning
SubplotsSeveral Axes on one Figure. plt.subplots(nrows, ncols) returns the Figure and an array of Axes.
axs.flatWalks through every panel of the array row by row, whatever its shape.
Squeezeplt.subplots drops dimensions of length one: one row gives a 1-D array, one panel a single Axes. squeeze=False keeps 2-D.
Shared axessharex=True / sharey=True: panels use one scale, so positions compare across panels.
suptitle / supylabelA title or axis label for the whole figure, not one panel.
subplot_mosaicAn uneven layout drawn as a picture of names; returns a dictionary of Axes.
Twin axisax.twinx(): a second y axis on the right with its own, arbitrary scale.
Secondary axisax.secondary_yaxis("right", functions=(f, g)): the same quantity in a second unit, tied by a formula.
Small multiplesThe same small chart repeated once per group, with the same axes.
Finding titleA title that states what the chart shows, with a subtitle that says what is plotted.
Locator / formatterWhere the ticks go / what text each tick shows.
Gray plus oneOne series in color, the rest in gray as context: color used to direct attention.
Qualitative / sequential / divergingPalettes for unordered groups / low-to-high numbers / numbers with a meaningful midpoint.
Direct labelA series' name written next to the series itself, replacing a legend.
Chart junkInk that carries no information: extra spines, tick marks, heavy grids, redundant labels.
rcParams / rc_contextMatplotlib's defaults, and a with block that changes them for the charts drawn inside it only.
