Session 17: Scraping Static and Dynamic Pages

Your pages for Session 17. Before the break: turning a web page into a checked table with Beautiful Soup. After the break: pages that JavaScript fills in, and how to collect them honestly, with the data file first and a browser only when you must.

Lessons 6.2–6.3 Session 17 · 3 hours Name: ____________________

Session Goals

  • read a page as a tree and choose selectors that describe meaning, not position
  • turn one repeated block of HTML into one dictionary, with missing values handled on purpose
  • follow pagination to the end, check a scrape against the page's own count, and read real tables with read_html
  • tell a static page from a dynamic one, and look for the data file before reaching for a browser
  • drive headless Chrome with Selenium: wait for things by name, click, fill a form, and always quit
The six ground rules (every Module 6 session starts here)
  1. Read robots.txt and obey it. It is the owner's published request to programs: where they may go and how fast.
  2. Read the terms of use. If they forbid automated collection, the answer is no, however easy the code would be.
  3. Prefer an API or a download when one exists. It is the front door.
  4. Go slowly and say who you are. Pause between requests; send a User-Agent with a way to contact you.
  5. Never go around a login, a paywall or a block. If you are asked to stop, stop.
  6. Do not collect personal data. Names, emails, profiles and photos of real people are protected by law in many places.

6.2

Parsing HTML with Beautiful Soup

Key ideas
  • Pass resp.content (bytes) to BeautifulSoup(..., "html.parser"): it reads the page's own charset.
  • find() / select_one() return one element or None. find_all() / select() return a list, maybe empty.
  • Choose labels, not positions: li.product-card p.price, not main > ul > li:nth-of-type(3).
  • Prefer data- attributes (data-price) to formatted text ($299.95). Everything from HTML is a string: convert it.
  • Find the repeated block, then write one function that turns one block into one dictionary.
  • Missing attribute: tag["x"] raises KeyError, tag.get("x") gives None. Missing element: select_one gives None. Decide per field what missing should mean.
  • Follow the "next" link until there is none, pause between requests, and keep a page limit.
  • Check before you trust: the page's count, unique keys, plausible values.
  • pd.read_html(io.BytesIO(resp.content)) reads real tables; pick one with attrs={"id": ...}.

Worked example: the climbing gear that is running out

Question: which climbing products are low on stock or out of stock? The stock label is deep inside each card, so start from the label and walk up to the card with find_parent("li").

climb = get_soup(urljoin(BASE_URL, "category-climbing.html"))
low = []
for label in climb.select("p.stock.low-stock, p.stock.out-of-stock"):
    card = label.find_parent("li")
    low.append({"sku": card["data-sku"],
                "name": card.select_one("h2.product-name a").get_text(strip=True),
                "price": float(card.select_one("p.price")["data-price"]),
                "stock": label["class"][1]})
print(pd.DataFrame(low).to_string(index=False))

6.3

Dynamic Pages with Selenium

Key ideas
  • Some pages arrive flat-packed: an empty frame, a data file, and JavaScript that assembles them. requests never runs the JavaScript.
  • Look for the data first: the Network tab (Fetch/XHR) or the page's script. If you may request the file, do that.
  • Drive a browser only when you must: the data is assembled in the page, it takes interaction to reveal, or you need what a person sees.
  • webdriver.Chrome(options=...) starts a real browser; Selenium Manager fetches the driver the first time.
  • find_element returns one element or raises; find_elements returns a list, maybe empty.
  • Never sleep. Wait by name: WebDriverWait(driver, 10).until(EC.presence_of_element_located((By.ID, "x"))), with the locator as one tuple.
  • Let Selenium render, then parse driver.page_source with Beautiful Soup.
  • A GET form is a slow way of building a URL: urlencode builds it directly.
  • driver.quit() in a finally block, every time.

Glossary

Element: one piece of HTML: a tag name, attributes (class, href, data-sku) and content.

Beautiful Soup: the library (bs4) that turns HTML into a tree you can search.

CSS selector: a pattern such as li.product-card p.price that names elements by tag, class, id or attribute.

select / select_one: every match as a list / the first match or None.

data- attribute: a machine-readable value a site stores for its own scripts, such as data-price="299.95".

Pagination: a listing split over pages, joined by "next" links.

read_html: pandas' reader for real <table> elements; it returns a list of DataFrames.

Dynamic page: a page whose content is added by JavaScript after it loads.

Selenium: a library that drives a real browser from Python.

Headless: a browser running without a window.

Explicit wait: WebDriverWait(driver, 10).until(condition): wait for a named condition, up to a limit.

WebElement: Selenium's handle on one live element; stale after the page changes.

page_source: the browser's current HTML, after scripts have run.
