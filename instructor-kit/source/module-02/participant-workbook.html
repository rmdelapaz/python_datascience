Vectorized Operations

By the end you can
  • Combine arrays element by element with arithmetic and with universal functions such as np.sqrt, np.log10 and np.maximum
  • Build boolean masks with comparisons, combine them with &, | and ~, and use them to count, filter and assign
  • Choose values by condition with np.where and np.select
  • Summarize a two-dimensional array along rows or columns with axis=, and predict the shape of the result
  • Rewrite a Python loop over numbers as an array expression and check that both give the same answer
Key ideas
  • Vectorized means one operation on a whole array, with the loop running inside NumPy's compiled code.
  • Parallel arrays line up by position: element 0 of every column describes the same store-day. A mask built from one column can filter another.
  • A comparison makes a mask of True and False. Its sum counts, its mean is a fraction, and inside square brackets it filters.
  • **Combine masks with & (and), | (or), ~ (not)**, and put parentheses around every comparison. Never and / or.
  • **np.where(cond, a, b) is an if/else for every element. np.select** handles three or more outcomes; the first true condition wins.
  • The axis you name is the axis that disappears. For a days-by-stores table, axis=0 gives one value per store and axis=1 one per day. Check the shape of the result.
  • **argmax and argsort return positions.** Use a position to look something up in a parallel array: days[week.argmax()].
  • **nan fails every comparison**, so missing values silently drop out of both groups. Test with np.isnan on purpose.
  • A mask gives a copy; a slice gives a view. Assign through the mask (x[x > 10] = 10) to change the array itself.

Worked example: do sale days mean bigger baskets?

On sale days the stores take in almost twice the revenue. Is that because each customer buys more items, or because there are more customers? units / transactions is the number of items in an average purchase.

units = load(4)
transactions = load(3)
promo = load(7)

per_sale = units / transactions            # items per purchase, every store-day
print(per_sale[:4].round(2))
print(per_sale.mean().round(2), per_sale.min().round(2), per_sale.max().round(2))
[2.16 2.02 2.18 2.09]
2.11 1.68 2.68

One division gives 2,903 answers. A typical purchase is about two items, and the figure never strays far: 1.68 to 2.68.

is_promo = promo == 1

print(is_promo.sum(), "sale store-days")
print(per_sale[is_promo].mean().round(2), "items per purchase on sale days")
print(per_sale[~is_promo].mean().round(2), "items per purchase on ordinary days")
96 sale store-days
2.11 items per purchase on sale days
2.11 items per purchase on ordinary days

The mask is built from promo and used on per_sale: parallel arrays. The two averages are the same to two decimals. Sale days do not make baskets bigger.

print(transactions[is_promo].mean().round(1), "purchases on a sale day")
print(transactions[~is_promo].mean().round(1), "purchases on an ordinary day")

large = per_sale >= 2.3
print(large.sum(), "large-basket days;", (large & is_promo).sum(), "of them were sale days")
155.4 purchases on a sale day
81.5 purchases on an ordinary day
194 large-basket days; 0 of them were sale days

What changes is the number of purchases. And of the store-days with unusually large baskets, none at all were sale days. An honest "no difference" is a finding too: the sale brings more buyers, not bigger baskets.

1.3

Broadcasting

By the end you can
  • State the broadcasting rules and use them to predict the shape of a result, or that an operation will fail
  • Combine a 2-D table with a row of values and with a column of values
  • Reshape an array for broadcasting with np.newaxis, reshape and keepdims=True
  • Build a grid of every combination from two 1-D arrays
  • Recognize the broadcasting mistakes that raise no error, and catch them by checking shapes
Key ideas
  • Broadcasting lets NumPy combine arrays of different shapes by reusing the smaller one, like a rubber stamp pressed on every line of a form.
  • Rule 1: write the shapes one above the other, lined up on the right. A missing entry counts as 1.
  • Rule 2: each pair of lengths must be equal, or one of them is 1. The result takes the larger of each pair. Any pair that fails is an error.
  • Per column (per store): a table and a row. table - table.mean(axis=0) just works.
  • Per row (per day): a table and a column. table / table.sum(axis=1, keepdims=True).
  • A column meeting a row builds a grid of every combination, whether you wanted one or not.
  • Standardizing is one line: (table - table.mean(axis=0)) / table.std(axis=0). It puts columns of different sizes on one scale.
  • The dangerous mistakes are silent. After any operation that mixes shapes, print .shape: four values in should mean four values out.

Worked example: how many staff does each store need?

Week 1 of visitors as a 7 by 4 table (days by stores: Asheville, Bend, Boise, Flagstaff). Three questions, three shapes: a table and a row, a table and a column, and a column meeting a row.

visitors = load(2)
V = visitors[:28].reshape(7, 4)

store_mean = V.mean(axis=0)                 # shape (4,)
print(store_mean.round(1))
print((V - store_mean).round(0)[-2:])       # Saturday and Sunday, against each store's own average
[239.3 268.4 380.4 207.4]
[[139. 156. 119.  38.]
 [-28.  16.  84.  48.]]

(7, 4) with (4,): from the right, 4 meets 4, and 7 meets a missing axis. The row of averages is reused on all seven days. Saturday is far above normal at every store.

share = V / V.sum(axis=1, keepdims=True)    # (7, 4) with (7, 1)
print(share.round(2)[:2])                   # Monday and Tuesday
print(share.sum(axis=1))
[[0.23 0.23 0.38 0.16]
 [0.23 0.24 0.33 0.2 ]]
[1. 1. 1. 1. 1. 1. 1.]

(7, 4) with (7, 1): 4 meets 1, 7 meets 7. Each day is divided by its own total, and the check line shows every row adding up to 1. Without keepdims=True the totals would be flat, 4 would meet 7, and NumPy would refuse.

per_staff = np.array([40, 50, 60])          # visitors one staff member can look after
needed = np.ceil(store_mean / per_staff[:, np.newaxis])    # (4,) with (3, 1)
print(needed.shape)
print(needed)
(3, 4)
[[ 6.  7. 10.  6.]
 [ 5.  6.  8.  5.]
 [ 4.  5.  7.  4.]]

(4,) with (3, 1): 4 meets 1, and a missing axis meets 3. A row meets a column, so the result is a 3 by 4 grid: one row per staffing level, one column per store. At 50 visitors per staff member Boise needs 8 people on an average day and Asheville 5.

Glossary

Vectorized operationOne operation applied to a whole array, with the loop running inside NumPy.
Parallel arraysArrays of the same length where position k in each describes the same thing (the same store-day).
ufunc (universal function)A NumPy function that applies itself to every element: np.sqrt, np.abs, np.maximum.
Boolean maskAn array of True and False made by a comparison. Used to count, filter and assign.
**&, |, ~**And, or, not for masks. Each comparison needs its own parentheses.
np.whereA vectorized if/else: np.where(condition, value_if_true, value_if_false).
np.selectA vectorized if/elif/else for three or more outcomes; the first true condition wins.
AggregationAn operation that boils many values down to one: sum, mean, max, std.
axisThe dimension an aggregation collapses. The axis you name is the axis that disappears.
argmax / argsortThe position of the largest value / the positions that would sort the array.
BroadcastingNumPy's rules for combining arrays of different shapes by reusing the smaller one.
keepdims=TrueKeeps the collapsed axis with length 1, so the result is a column (or row) that broadcasts.
np.newaxisAdds an axis of length 1 when indexing: a[:, np.newaxis] turns (n,) into (n, 1).
GridThe table of every combination that results when a column meets a row.
z-scoreHow many standard deviations a value is above or below its column's mean.
