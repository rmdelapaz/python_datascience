7.1

Statistical Graphics with Seaborn

By the end you can
  • Draw scatter, line, histogram, ECDF, box, bar and point charts from a tidy table with one call each
  • Tell an axes-level function from a figure-level one and pick the right one
  • Split a chart with hue, col and row instead of a loop
  • Say what an error bar or band shows, and set it with errorbar=
  • Finish a seaborn chart with Matplotlib
Key ideas
  • Seaborn sits on Matplotlib. Every seaborn chart is a Matplotlib figure. You name the table and the roles: sns.something(data=table, x="col", y="col", hue="col").
  • Tidy in, chart out. One row per observation, one column per variable. If a chart is hard to describe, reshape with melt first.
  • Axes-level functions (scatterplot, lineplot, histplot, ecdfplot, boxplot, barplot, pointplot, heatmap) take ax= and return that Axes. Use them inside your own plt.subplots() layout.
  • Figure-level functions (relplot, displot, catplot) make their own figure, build panels from col= and row=, and return a FacetGrid. Size them with height= and aspect=.
  • Seaborn aggregates. lineplot, barplot and pointplot draw the mean of the rows that share an x, plus a bootstrapped 95% confidence interval. A band you did not expect means several rows per x.
  • Two kinds of error bar. Spread of the data ("sd", ("pi", 50)) or uncertainty of the estimate (("ci", 95), "se"). Uncertainty shrinks as the sample grows; spread does not. Always say which one you drew.
  • Order is your job. Categories appear in first-seen order. Pass order=, hue_order=, col_order=.
  • sns.set_theme(style="whitegrid", palette="colorblind") once, at the top. Pass seed= to make bootstrapped bars repeatable.

Worked example: one line, two bands

The weather table has 731 days for each of the four store cities. The same lineplot call is drawn twice; only errorbar= changes. The printed table is July in numbers.

weather = pd.read_csv("data/store_weather.csv", parse_dates=["date"])
weather["month"] = weather["date"].dt.month
fig, axes = plt.subplots(1, 2, figsize=(10, 3.6), sharey=True, layout="constrained")
sns.lineplot(data=weather, x="month", y="high_f", hue="city",
             errorbar=("ci", 95), seed=42, ax=axes[0])
axes[0].set_title("Band: 95% CI of the mean", loc="left")
sns.lineplot(data=weather, x="month", y="high_f", hue="city",
             errorbar="sd", legend=False, ax=axes[1])
axes[1].set_title("Band: mean +/- 1 standard deviation", loc="left")
fig.savefig("highs_two_bands.png", dpi=150)
july = weather[weather["month"] == 7].groupby("city")["high_f"]
july = july.agg(n="count", mean="mean", sd="std", se="sem")
print(july.round(2))

Read July in the table. Each city has 62 July days. The standard deviation is about 7 to 9 degrees: that is how much one July day differs from another, and it is the width of the right-hand band. The standard error is about 1 degree: that is how well we know the July average, and it is why the left-hand band is almost too thin to see. Same data, same line, two honest bands that answer different questions.

7.2

Interactive Charts with Plotly

By the end you can
  • Build line, scatter, bar, box and heatmap charts with one Plotly Express call each
  • Design what a reader sees on hover
  • Finish a figure with update_layout, update_xaxes, update_yaxes and update_traces
  • Add reference lines, shaded regions and annotations
  • Save a standalone HTML file and say what data is inside it
Key ideas
  • A figure is a description: traces (the data) plus a layout (titles, axes, legend). Python builds it; plotly.js draws it in a browser. Inspect it: fig.data[0].type, len(fig.data), fig.layout.title.text.
  • Nothing shows until you ask: fig.show() in a notebook, or fig.write_html("chart.html") and open the file.
  • Plotly Express follows the seaborn pattern with different words (table below).
  • `px.bar` and `px.line` do not aggregate. They draw one mark per row. Summarize with groupby first, then plot the summary.
  • Design the hover. hover_name= is the bold first line; hover_data={"revenue": ":$,.0f"} adds and formats columns; hovertemplate gives full control; hovermode="x unified" suits time series.
  • The title is still the message. Most readers look at the default view for a few seconds.
  • `write_html` choices: include_plotlyjs=True (default, about 4.7 MB, works offline) or "cdn" (a few KB, reader must be online).
  • The data is in the file. Every x, y and hover column is readable text inside the HTML. Aggregate first and pass only the columns the chart needs.

Worked example: aggregate first, then one call

How do people pay, online and in the stores? The orders table has 20,302 rows; the chart needs eight numbers. Count with pandas, turn counts into shares within each channel, and hand Plotly that small table.

orders = pd.read_csv("data/orders.csv")
mix = orders.groupby(["channel", "payment_method"], as_index=False).size()
mix["share"] = mix["size"] / mix.groupby("channel")["size"].transform("sum")
print(mix.round(3).to_string(index=False))
methods = ["card", "digital_wallet", "gift_card", "cash"]
fig = px.bar(mix, x="payment_method", y="share", color="channel", barmode="group",
             text_auto=".0%", category_orders={"payment_method": methods},
             labels={"share": "Share of orders", "payment_method": ""},
             title="Cash is a store-only habit; wallets are an online one")
fig.update_yaxes(tickformat=".0%")
fig.write_html("payment_mix.html", include_plotlyjs="cdn")
print(len(fig.data), "traces |", [len(t.x) for t in fig.data], "bars each")

Glossary

  • Tidy (long) table: one row per observation, one column per variable: the shape seaborn and Plotly Express expect.
  • Semantic mapping: giving a column a role in the chart: x, y, hue (color), size, style.
  • Axes-level function: a seaborn function that draws on one Matplotlib Axes (takes ax=, returns the Axes).
  • Figure-level function: relplot, displot or catplot: makes its own figure and returns a FacetGrid.
  • FacetGrid: seaborn's object for a grid of panels; g.figure and g.axes reach the Matplotlib parts.
  • Small multiples: the same chart repeated once per group with shared axes.
  • Estimator: the statistic a chart draws for each group; the mean unless you change it.
  • Confidence interval: a range for an estimate such as a mean; it narrows as the sample grows.
  • Bootstrap: resampling your own rows with replacement many times to see how much an estimate moves.
  • ECDF: empirical cumulative distribution: the share of values at or below each x; no bins to choose.
  • Trace: one data series in a Plotly figure (a line, a set of bars, a set of points).
  • Layout: everything in a Plotly figure that is not data: title, axes, legend, shapes, annotations.
  • Hover template: the small text pattern, with placeholders such as %{y:$,.0f}, that fills the hover label.
  • CDN: a public server the reader's browser downloads plotly.js from when the file was written with include_plotlyjs="cdn".
  • Kaleido: the helper package write_image uses to turn a Plotly figure into a PNG, SVG or PDF; it needs Chrome.
