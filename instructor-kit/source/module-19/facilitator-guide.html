How to teach the session where charts start doing statistics and then start answering back. Before the break, seaborn: describe a chart by naming columns, and learn to say exactly what an error bar shows. After it, Plotly: a chart the reader can hover, zoom and filter, in one HTML file that carries its data with it.

The one risk of Session 19: charts that look right and say something else

Both libraries will happily compute or skip a statistic without telling you. Seaborn aggregates silently (lineplot, barplot and pointplot draw a mean and an interval you did not ask for). Plotly Express does not aggregate at all (px.bar stacks every row). Neither raises an error. Say the two rules early and keep pointing at them: "In seaborn, ask what the bar shows. In Plotly, aggregate first." The second risk comes at the end: an HTML chart carries its data. Learners are two sessions from a capstone they may publish, so the habit of passing a figure only the columns it needs starts today.

Warm-up: Retrieval from Session 18

10 min
How to run it

Six minutes, no notes, answers on paper, then two minutes of answers called out and two for the homework check. These reach back to Lessons 6.4 and 6.5: the point is retrieval, not a grade.

Five questions (with answers)
  1. A request comes back 401. Another comes back 403. What does each one tell you, and what should your client do next? Answer: 401: the server does not know who you are (no token, or token_expired): log in again and repeat the request once. 403: it knows who you are and refuses: stop and fix the credential or the permission. Neither is retried in a loop.
  2. Where does an API key live while you work on a notebook you will share, and where in the request does it travel? Answer: In an environment variable (or typed at a prompt), read at run time; never in the code. It travels in a header (X-API-Key), not in the URL, because URLs end up in logs and browser history.
  3. The server answers 429 with the header Retry-After: 4. What does a polite client do? What if the header is missing? Answer: Wait at least 4 seconds, then send the same request again. With no header, fall back to a default wait (exponential backoff with jitter), with a maximum number of tries.
  4. What does this print? 
    print([min(4.0, 1.0 * 2 ** n) for n in range(4)])
    Answer: [1.0, 2.0, 4.0, 4.0]: the delay doubles (1, 2, 4) and then the cap of 4.0 holds it. That is exponential backoff with a ceiling; real clients add random jitter on top.
  5. Name two failures a retry policy should retry and two it never should. Then: what made the Lesson 6.5 download resumable? Answer: Retry: 429, 5xx, timeouts (temporary). Never: 400, 401, 403, 404 (the same request will fail the same way). Resumable: each page is saved to its own file as soon as it arrives, written completely or not at all, and pages whose files exist are skipped.

Mental model to say (12 min frame)

"Matplotlib is a drawing table with excellent pens: put a dot here, a line there. Seaborn is an assistant at the same table who takes orders at a higher level: revenue against visitors, one color per store. The assistant splits the table into groups, picks colors, computes any averages and intervals, draws with the same pens and writes the legend. When the assistant is done, you can still pick up a pen."

Three mistakes to expect
  • Passing `ax=` to `relplot`, `displot` or `catplot` (or the reverse: expecting col= to work on scatterplot). Symptom: two figures, one empty, and a UserWarning that scrolls by unread. Coach: "Read the last sentence of the warning. Who owns the figure in your plan, you or seaborn?" Point at the two boxes on the board.
  • Reading a band or bar without knowing what it is. A learner draws lineplot on daily rows and describes the band as "the range". Coach: "How many rows share each x? Print groupby(...).size(). What did seaborn have to do to get one y?" Then: "Which errorbar= would give you the range you had in mind?" (("pi", 100).)
  • Categories in first-seen order. Weekdays come out Mon, Tue, ... only by luck of the file; age groups come out 65+, 18-24, 25-34. There is no error, so it reaches the saved figure. Coach: "Read your x axis aloud, left to right. Is that the order you would say them in?" Fix: order=, hue_order=, col_order=.

Mental model to say (12 min frame)

"A static chart is a map printed on the wall: beautifully composed, the same for everyone, fixed. An interactive chart is a map app: the reader pinches to zoom, taps a pin, switches layers. You, the mapmaker, still decide what is on the map and what the default view is. The reader decides where to look next."

Then the mechanism, in one breath, with the lesson's flow diagram on screen: "Your Python does not draw anything. It builds a figure: traces (the data) plus a layout (titles, axes, legend). That description goes, as JSON text, to a JavaScript library, plotly.js, which draws it in a browser. A notebook is a web page. An HTML file is a web page. That is why the chart works in both, and why the data is in the file." Write on the board: figure = data + layout and aggregate first.

Three mistakes to expect
  • Handing `px.bar` or `px.line` unaggregated rows. Fresh from seaborn, learners expect a mean. They get 2,903 stacked slivers, or a line that scribbles back and forth. No error. Coach: "Print len(fig.data[0].x). How many bars did you mean to draw?" Then: "Which pandas line makes that table?"
  • Seaborn words in a Plotly call: hue= for color=, col= for facet_col=, order= for category_orders={...}. The TypeError names the unexpected argument. Coach: point at the workbook's two-column translation table; do not supply the word.
  • Nothing appears, or the wrong thing is sent. A cell that ends with fig = px... shows nothing (no fig.show()); a script that calls fig.show() in the lab opens browser tabs for every run. And at the end, a learner writes the full sales table into an HTML file when the chart needed three columns. Coach: "Open your file in a text editor and search for a column you did not plot."

Exit ticket · 5 min (answers)
  1. You call sns.barplot(data=sales, x="store", y="revenue") and black lines appear on the bars. What are they, by default, and which argument changes them? Answer: A bootstrapped 95% confidence interval for the mean of each bar (uncertainty of the estimate, not spread of the days). errorbar= changes it: "sd", "se", ("pi", 50) or None. Say which one in the caption.
  2. Give one job for an axes-level function and one for a figure-level function. Answer: Axes-level (scatterplot, histplot, barplot): one panel inside your own plt.subplots() layout, with ax=. Figure-level (relplot, displot, catplot): seaborn builds a grid of panels from a column with col= / row= and returns a FacetGrid.
