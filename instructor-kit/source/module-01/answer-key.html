Start Here · Diagnostic

Not graded. The reasoning for each answer also says where the skill comes back in this course.

D1
What does this print?
days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
print(days[-2:], days[1:3])
A) ['Sat', 'Sun'] ['Tue', 'Wed']
B) ['Sun'] ['Tue', 'Wed', 'Thu']
C) ['Sat', 'Sun'] ['Mon', 'Tue', 'Wed']
D) ['Fri', 'Sat'] ['Tue', 'Wed']
Why: A negative start counts from the end, and a slice leaves out its stop position. Array slicing in Lesson 1.1 uses exactly these rules, then adds a second dimension. Skill: slicing. Review if missed: Intro Python: lists and slicing.
D2
What does this print?
a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
print(a, c)
A) [1, 2, 3] [1, 2, 3]
B) [1, 2, 3, 4] [1, 2, 3, 4]
C) [1, 2, 3, 4] [1, 2, 3]
D) [1, 2, 3] [1, 2, 3, 4]
Why: b = a is a second name for the same list; a[:] is a copy. This is the idea behind views and copies today, with one twist: a slice of an ARRAY is not a copy. Skill: names and copies. Review if missed: Intro Python: lists are mutable; two names, one list.
D3
What does this print?
stock = {"tent": 4, "stove": 0}
stock["lamp"] = stock.get("lamp", 0) + 2
print(len(stock), stock["lamp"])
A) 2 2
B) 3 2
C) A KeyError
D) 3 None
Why: .get("lamp", 0) returns 0 for a missing key instead of raising an error, so the new key is created with 0 + 2. Counting with a dictionary is what value_counts() does for you in pandas. Skill: dictionaries. Review if missed: Intro Python: dictionaries and .get().
D4
What does this print?
def with_tax(price, rate=0.08):
    return round(price * (1 + rate), 2)

print(with_tax(50), with_tax(50, rate=0.10))
A) 54.0 54.0
B) 4.0 5.0
C) None None
D) 54.0 55.0
Why: The first call uses the default rate, the second overrides it with a keyword argument, and the function returns its result. Every library call in this course works this way: read_csv(path, parse_dates=[...]). Skill: functions. Review if missed: Intro Python: functions, return values, default arguments.
D5
What does this print?
totals = [434.90, 75.90, 399.80, 26.71]
big = [t for t in totals if t >= 100]
print(len(big), max(big))
A) 2 434.9
B) 4 434.9
C) 2 399.8
D) 3 434.9
Why: The condition keeps 434.90 and 399.80. Filtering rows with a condition is the most common move in data analysis; Lesson 1.2 does it without the loop. Skill: comprehensions. Review if missed: Intro Python: list comprehensions with a condition.
D6
A row read from a CSV file with the csv module looks like this. What does the code print?
row = {"store": "Boise", "revenue": "5962.0"}
print(row["revenue"] * 2)
A) 11924.0
B) 5962.05962.0
C) A TypeError
D) 5962.0 2
Why: Everything in a text file arrives as text, and text times 2 repeats. float(row["revenue"]) * 2 gives 11924.0. NumPy and pandas do this conversion for you, which is why checking the dtype matters. Skill: text from files. Review if missed: Intermediate Python: reading files; values in a text file are strings.

0.1 · Your Data Science Toolkit: self-check

Q1
Your terminal prompt starts with (.venv). What does that tell you?
A) Python is running inside a notebook
B) This terminal will use the project's own Python and the packages installed for it
C) The course packages are being downloaded right now
D) The data folder was found
Why: The prefix appears when the virtual environment is active in this terminal window. From then on python and python -m pip mean the ones inside .venv.
A is wrong: A notebook runs in a browser tab or an editor; the prompt prefix is about the terminal.
C is wrong: Activating installs nothing. Installing is a separate command, run once.
D is wrong: Activation knows nothing about your data. Path("data/orders.csv").exists() answers that question.
Q2
Which command installs every package the course needs, using the pip that belongs to the active environment?
A) pip install requirements.txt
B) python requirements.txt
C) python -m venv requirements.txt
D) python -m pip install -r requirements.txt
Why: python -m pip runs the pip of the Python that is active, and -r tells it to read package names from the file.
A is wrong: Without -r pip looks for a package that is literally named requirements.txt. A bare pip may also belong to a different Python.
B is wrong: That asks Python to run the text file as a program, which fails on the first line that is not Python.
C is wrong: That would create a new environment in a folder called requirements.txt.
Q3
The status column of orders holds completed 18,762 times, returned 1,143 times and cancelled 397 times. What does this print?
print(len(orders[orders["status"] == "returned"]))
1143
Why: The expression in the brackets keeps only the rows where the status is exactly "returned", and len counts the rows that are left.
Q4
A script stops with this traceback. What is the most useful first step?
Traceback (most recent call last):
  File "/home/you/pinecrest-analysis/report.py", line 4, in <module>
    print(orders["Order Total"].sum())
  ...
KeyError: 'Order Total'
A) Print orders.columns and copy the exact column name from there
B) Reinstall pandas, because the error happened inside it
C) Restart the computer and run the script again
D) Change the path to use backslashes
Why: Read the last line first: a KeyError from a table means there is no column with exactly that name. The real name is order_total.
B is wrong: The last line names your key, not a problem with pandas. Library lines in a traceback are rarely where the mistake is.
C is wrong: The same code gives the same error every time.
D is wrong: The error is about a column name, not about a file path.
Q5
In a notebook, cell 1 loads orders and cell 3 prints orders.shape. You restart the kernel and run only cell 3. What happens?
A) Cell 3 prints the shape, because the notebook file remembers the table
B) A FileNotFoundError, because the data folder is closed
C) A NameError: the name orders is not defined
D) Nothing is printed and there is no error
Why: Restarting the kernel clears every variable. Until cell 1 runs again there is nothing called orders. Run the cells from the top.
A is wrong: The file stores your code and the old outputs, not the variables in memory.
B is wrong: No file is being opened in cell 3.
D is wrong: Using a name that does not exist always raises an error.
Q6
Python is working in your project folder, which contains data/orders.csv (and no file called order.csv). What does this print?
from pathlib import Path

print(Path("data/orders.csv").exists(), Path("data/order.csv").exists())
True False
Why: A relative path is looked up from the folder Python is working in. The first file is there; the second name is missing an s, so it is not.

P1
Two numbers. Which one is bigger, and roughly by how much?
print(len(orders), len(orders[orders["channel"] == "store"]))
20302 7448
Why: All 20,302 orders, then only the 7,448 placed in a store. A filter can only keep rows, never add them, so the second number is never larger than the first.
P2
The file covers two calendar years. What does this print?
print(orders["order_date"].min().year, orders["order_date"].max().year)
2024 2025
Why: .min() and .max() work on dates as they do on numbers: the earliest order is in 2024 and the latest in 2025. This only works because parse_dates turned the text into real dates when the file was loaded.
P3
This line has a mistake in it. Predict the kind of error and its message.
orders["Status"]
KeyError: 'Status'
Why: Column names must match exactly, capitals included. The column is status. print(orders.columns) shows the real names.

1.1 · Arrays vs Lists: self-check

Q7
What does this print?
a = [1, 2, 3]
b = np.array([1, 2, 3])
print(a * 2, b * 2)
A) [1, 2, 3, 1, 2, 3] [2 4 6]
B) [2, 4, 6] [2 4 6]
C) [1, 2, 3, 1, 2, 3] [1 2 3 1 2 3]
D) A TypeError
Why: For a list, * means repeat. For an array, * is arithmetic on every element.
B is wrong: A list never does arithmetic on its items; you would need a loop or a comprehension.
C is wrong: An array never repeats itself with *; it multiplies.
D is wrong: Both operations are allowed. They just mean different things.
Q8
What does this print?
t = np.arange(12).reshape(3, 4)
print(t[1, 2], t[:, 0])
6 [0 4 8]
Why: The table is 0 to 11 in three rows of four. Row 1, column 2 is 6. A lone colon means every row, so t[:, 0] is the first column: 0, 4, 8.
Q9
What does this print?
a = np.array([5, 6, 7, 8])
b = a[1:3].copy()
b[0] = 0
print(a)
A) [5 0 7 8]
B) [5 6 7 8]
C) [0 6 7 8]
D) [5 0 0 8]
Why: .copy() makes an independent array, so writing to b cannot reach a.
A is wrong: That is what happens WITHOUT .copy(): a plain slice is a view, and b[0] is a[1].
C is wrong: b[0] is the first element of the slice, which started at position 1 of a, not position 0.
D is wrong: Only one element was assigned.
Q10
What is the dtype of np.array([1, 2.5, 3])?
print(np.array([1, 2.5, 3]).dtype)
A) int64
B) object
C) <U32
D) float64
Why: An array has one type. A float can hold 1 and 3, but an integer cannot hold 2.5, so NumPy promotes everything to float64.
A is wrong: An integer array would have to drop the .5.
B is wrong: NumPy only falls back to object when you ask for it or when the values have no common type.
C is wrong: That is a text dtype; it appears when a string is mixed in with the numbers.
Q11
What does this print?
r = np.array([10.0, np.nan, 30.0])
print(r.mean(), np.nanmean(r))
nan 20.0
Why: Any arithmetic that touches a nan gives nan, so the plain mean is nan. np.nanmean skips the missing value and averages the two that are present.
Q12
Which job suits a Python list better than a NumPy array?
A) Raising two million prices by 8%
B) Totaling each column of a days-by-stores table
C) Collecting sensor readings one at a time when you do not know how many there will be
D) Storing five million revenue figures in as little memory as possible
Why: An array's size is fixed, so every np.append copies everything. Collect in a list, convert once with np.array(the_list), then compute.
A is wrong: Whole-array arithmetic is the array's best job: one expression, compiled speed.
B is wrong: Columns of a 2-D array are one expression, table[:, k].sum(); a list of lists needs a loop.
D is wrong: An array stores 8 bytes per number; a list needs about 32 to 36.

1.1 · Arrays vs Lists: predict, then run

P1
What does this print?
x = np.array([1, 2, 3])
print(x + x, [1, 2, 3] + [1, 2, 3])
[2 4 6] [1, 2, 3, 1, 2, 3]
Why: + on arrays adds element by element; + on lists joins them end to end. Same symbol, two meanings, just like *.
P2
What does this print?
g = np.arange(6).reshape(2, 3)
row = g[0]
row[:] = 9
print(g)
[[9 9 9]
 [3 4 5]]
Why: g[0] is a view of the first row, so filling row with 9 writes into g. row = g[0].copy() would have left g as it was.
P3
What does this print?
z = np.zeros(3, dtype=np.int64)
z[0] = 2.99
z[1] = True
print(z)
[2 1 0]
Why: The array is int64 and stays int64. 2.99 is chopped to 2 (not rounded to 3), True becomes 1, and the third value was never touched.

Lab 1.1-A: labs/module-01/l1_1-arrays-vs-lists/transactions_week_starter.py → transactions_week_solution.py

Reference output: first eight values [51. 52. 68. 33. 39. 45. 73. 39.]; shape (2903,), dtype float64, ndim 1, size 2903; missing values 0; the week table (7 rows, 4 columns, first row [61. 49. 63. 28.], last row [57. 73. 130. 57.]); Saturday [93. 59. 151. 71.]; Bend [49. 42. 39. 46. 66. 59. 73.]; Boise on Saturday 151.0; busiest store-day 151.0; float64: 224 bytes | int16: 56 bytes; same values True.

The solution's key lines:

week2 = transactions[28:56].reshape(7, 4)     # 7 days x 4 stores, a view
print(week2[5])        # Saturday, every store
print(week2[:, 1])     # Bend, every day
print(week2[5, 2])     # Boise on Saturday
small = week2.astype(np.int16)

Why: the file is sorted by date and then store, and early January has no gaps, so 28 consecutive values are exactly 7 days of 4 stores, and reshape(7, 4) fills row by row. The solution also prints two extras worth showing in the debrief: week2 shares memory with the full column (True: slicing and reshaping copy nothing) but small does not (False: astype always builds a new array).

Common wrong results: ValueError: cannot reshape array of size 27 into shape (7,4) (stop of 55 instead of 56); a table of 4 rows whose first row is [61. 49. 63. 28. 42. 42. 69.], with no error at all (that is reshape(4, 7): each row now runs across two days and mixes the stores); Tuesday's row printed for Bend (week2[1] instead of week2[:, 1]); 112 bytes for the small table (int32, not int16).

Lab 1.1-B: labs/module-01/l1_1-arrays-vs-lists/what_if_copy_starter.py → what_if_copy_solution.py

Reference output: the week-1 units table (first row [110 105 148 69]); Bend, real total: 868; bend shares memory with week1: True; Bend, what-if total: 938; Bend, real total: 868; what_if shares memory with week1: False; stored 97.6, got: 97 | dtype: int64; float version: 97.6 | dtype: float64; Bend, real total (still): 868.

The solution's key lines:

what_if = week1.copy()                    # independent table
what_if[:, 1] = what_if[:, 1] + 10       # Bend's column, in the copy only
trap = week1[:, 1].copy()
trap[0] = 97.6                           # int64 array: stored as 97
fixed = week1[:, 1].astype(np.float64)   # a float array can hold 97.6

Why: seven days times 10 units is 70, so 868 becomes 938 in the copy and the original must still say 868. The integer trap is Common Mistake 4 from the lesson on real numbers: an array never changes its dtype to fit a value.

Common wrong results: the real total prints 938 after the what-if (what_if = week1 or what_if = week1[:, :]: both share memory with the original); shares_memory prints True for the what-if for the same reason; 98 expected for the trap (rounding was assumed; storing into an integer array chops).

Handout: labs/module-01/l1_1-arrays-vs-lists/debug_silent_traps.py (wrong answers, no error)

As shipped it prints dtype: <U32, average price: ['24.5' '39.0'], total stock: 4, Monday is still: 0. Block 1: the quotes around "82.00" turn the whole array into text; remove them and prices.mean() is 48.5. Block 2: 100 + 60 does not fit in int8 (limit 127) and wraps to -96, so the total is 4; drop dtype=np.int8 (or use int64) and the total is 260. The Lesson Pages' Own Quick Quizzes

Each lesson page ends with a five-question Quick Quiz (three options each). Learners do them at home; these are the answers with the page's own explanation.

Lesson 0.1 · Your Data Science Toolkit
  1. Question 1. Yesterday everything worked. Today you open a new terminal, go to your project folder, run python first_look.py, and get ModuleNotFoundError: No module named 'pandas'. What is the most likely cause?
    Answer: C) The virtual environment is not activated in this terminal. Activation applies to one terminal window. In a new one, python means the system Python again, which does not have the course packages. Activate the environment, look for (.venv) in the prompt, and run the script again.
  2. Question 2. A traceback fills your screen with thirty lines. Where should you look first?
    Answer: A) The last line, which gives the error type and message. The last line names the type of error and gives its message, which often tells you the cause outright. After that, scan upward for the line that belongs to your own file.
  3. Question 3. In a requirements file, what does pandas~=3.0.0 allow pip to install?
    Answer: B) Version 3.0.0 or any later 3.0.x release, but not 3.1. The compatible-release operator lets the last number written go up and nothing else. So 3.0.0, 3.0.6 and any other 3.0.x are allowed, while 3.1 and 4.0 are not.
  4. Question 4. The file orders.csv is definitely inside your data folder, yet pd.read_csv("data/orders.csv") raises FileNotFoundError in a notebook. What should you check?
    Answer: A) Which folder Python is working in, with Path.cwd(). A relative path is resolved from the folder Python is working in. If JupyterLab was started somewhere else, data/orders.csv points to a place that does not exist. Path.cwd() shows the working folder.
  5. Question 5. You want to try several ways of charting a dataset, looking at each result before deciding on the next step. Which fits best, and why?
    Answer: B) A notebook, because variables stay in memory and each result appears under its cell. A notebook keeps the loaded data in memory and shows each result under its cell, so you can change one step and rerun only that step. Once the analysis is settled, move it into a script so it runs the same way every time.
Lesson 1.1 · Arrays vs Lists
  1. Question 1. What does this print? 
    x = np.array([1, 2, 3])
y = x[:2]
y[0] = 99
print(x)
    Answer: B) [99 2 3]. Slicing an array gives a view of the same memory, so writing to y[0] changes x[0] as well. Use x[:2].copy() when you need an independent array.
  2. Question 2. One million whole numbers take about 36 MB as a Python list and 8 MB as an int64 array. What is the main reason?
    Answer: A) The list stores an address plus a full Python object for every number; the array stores only the raw values. A list stores an 8-byte address for each item, and each item is a full Python object of about 28 bytes carrying its own type information. The array stores the type once and then only the 8-byte values.
  3. Question 3. What does this print? 
    z = np.array([7, 8, 9])
z[1] = 4.9
print(z)
    Answer: C) [7 4 9]. z has dtype int64 and keeps it. Assigning 4.9 chops off the decimal part, leaving 4, with no warning. Create the array as float64 if decimals are possible.
  4. Question 4. sales has shape (3, 4): three days as rows, four stores as columns. Which expression gives every day's value for the store in column 1?
    Answer: B) sales[:, 1]. Rows come before the comma and columns after. A lone colon means every row, and 1 picks column 1, so the result has three values, one per day.
  5. Question 5. You are reading sensor values one at a time from a device and do not know how many there will be. Afterward you want their mean and maximum. What is the best approach?
    Answer: C) Append each value to a list, then convert the list to an array once and compute there. Lists are built for cheap appends and arrays are built for math. Collect in a list while the size is unknown, convert once with np.array(), and compute on the array.

Exit Ticket

E1
Your prompt does not start with (.venv). What will probably go wrong, and what do you type to fix it?
Python will not find the course packages (ModuleNotFoundError). Activate the environment: .venv\Scripts\Activate.ps1 on Windows, source .venv/bin/activate on macOS and Linux, from the project folder.
E2
a = np.array([1, 2, 3]), then b = a[:2] and b[0] = 9. What is a now, and what one change would have protected it?
[9 2 3]: a slice is a view of the same memory. b = a[:2].copy() makes an independent array.
E3
The mean of a revenue array prints nan. What does that tell you, and what do you use instead?
At least one value is missing, and arithmetic with a missing value gives a missing value. np.nanmean(revenue) skips them (np.isnan(revenue).sum() counts them).
