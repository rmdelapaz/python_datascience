Worked example: who pays for shipping?

A new question for the three moves. Shipping is charged on some online orders. How many orders paid each amount, and what share of online orders shipped free?

import pandas as pd

orders = pd.read_csv("data/orders.csv", parse_dates=["order_date"])
print(orders["shipping_cost"].value_counts())
shipping_cost
0.00     16624
6.95      2754
14.95      924
Name: count, dtype: int64

Three shipping prices: free, $6.95 and $14.95. But 16,624 free orders is more than all the online orders there are, because store orders never have shipping. The question is about online orders, so filter first.

online = orders[orders["channel"] == "online"]
free = online["shipping_cost"] == 0

print(len(online), "online orders")
print(free.sum(), "shipped free:", round(free.mean() * 100, 1), "percent")
12854 online orders
9176 shipped free: 71.4 percent

free is a column of True and False. Its .sum() counts the True values and its .mean() is the fraction that is True. Read the result as a sentence: about 71% of online orders shipped free.

1.1

Arrays vs Lists

By the end you can
  • Explain how a NumPy array stores numbers differently from a Python list, and why that makes it smaller and faster
  • Create arrays from lists, from scratch, and from a CSV file, and read their dtype, shape, ndim and size
  • Select elements, rows and columns with indexing and slicing in one and two dimensions
  • Predict whether an operation gives you a view or a copy, and make a copy when you need one
  • Measure memory and speed yourself and choose between a list and an array for a task
Key ideas
  • A list is an address book; an array is one block of values. The list keeps an address for every item and every item is a full Python object. The array stores the type once, then only the numbers.
  • Three rules: one type for the whole array (the dtype), a fixed size, and operations that act on every element at once.
  • *** 2 doubles an array; it repeats a list.** The same is true for +: arrays add element by element, lists join.
  • Mixed values are converted silently. One text value makes the whole array text. A decimal stored into an integer array is chopped. When in doubt, print .dtype.
  • Rows, comma, columns. table[row, col]; a lone : means all of them. Print .shape when you are not sure which is which.
  • A slice is a window, not a photocopy. Writing to a slice changes the original. .copy() gives you an independent array; np.shares_memory(a, b) settles any doubt.
  • Arrays do not grow. Collect in a list, convert once, compute on the array.
  • **nan means a missing value got into the calculation.** np.isnan(x).sum() counts them; np.nanmean, np.nansum, np.nanmax and np.nanmin skip them.

Worked example: two years of high temperatures as a table

data/store_weather.csv has one row per city per day: 731 days for each of four cities, sorted by city (Boise, Bend, Flagstaff, Asheville), then by date. Column 2 is the day's high in °F. Because every city has the same number of rows and nothing is missing, the whole column fits a 4 by 731 table.

import numpy as np

high = np.genfromtxt("data/store_weather.csv", delimiter=",", skip_header=1, usecols=2)
print(high.shape, high.dtype, np.isnan(high).sum())
(2924,) float64 0

2,924 values, all float64 (that is what genfromtxt gives unless told otherwise), none missing.

temps = high.reshape(4, 731)        # rows = cities, columns = days
print(temps.shape)
print(temps[0, :7])                 # Boise, first week of January 2024
print(temps[:, 0])                  # every city on 1 January 2024
(4, 731)
[37. 44. 30. 26. 29. 27. 32.]
[37. 37. 38. 49.]

Rows, comma, columns: temps[0, :7] is row 0 (Boise) and the first seven columns (days). temps[:, 0] is every row, column 0: one value per city. Boise's week matches the temperatures in the lesson's Exercise 1.

print(temps[2].mean().round(1))     # Flagstaff, average high over two years
print(temps.max(), temps.min())     # hottest and coldest high anywhere
print(np.shares_memory(temps, high))
60.0
112.0 10.0
True

temps[2] is all of Flagstaff's row. The last line prints True: reshaping gave the same memory a new shape, so temps is a view of high, not a copy.

Glossary

Virtual environmentA folder (.venv) holding one project's own copy of Python packages, separate from every other project.
PackageA library someone else wrote that you install and import, such as NumPy or pandas.
requirements.txtA text file listing the packages a project needs, one per line, usually with version pins.
NotebookA file of cells (.ipynb) that you run one at a time, with each result shown under its cell.
KernelThe Python process that runs a notebook's cells. It must be the course environment's Python.
ScriptA .py file that runs from top to bottom, starting fresh every time.
Relative pathA file location given from the folder Python is working in, such as data/orders.csv.
TracebackThe report Python prints when an error stops it. The last line names the error.
DataFramepandas' table: rows and named columns. Taught properly in Module 2.
Array (ndarray)NumPy's container: many values of one type in one block of memory.
dtypeThe single type shared by every element of an array, such as float64 or int64.
shapeThe length of an array along each dimension, as a tuple: (7,) or (3, 4).
VectorizationDoing an operation on a whole array in one expression instead of a Python loop.
ViewAn array that shares memory with another array. Writing to one changes the other.
CopyAn independent array with its own memory, made with .copy().
nan"Not a number": NumPy's marker for a missing value. Arithmetic that touches it gives nan.
