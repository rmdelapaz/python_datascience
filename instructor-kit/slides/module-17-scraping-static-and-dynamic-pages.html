A page is a tree. Read the labels.

6.2 · Why it matters

Twenty prices hide in twelve thousand characters

  • String hunting works for one page on one day
  • A tree with labels works on every page, every day
  • The same pattern for any listing: block → dictionary → DataFrame
  • And then you check it, because nobody designed the page as your data

The labeled filing cabinet

6.2 · Code

Follow next until there is none

def scrape(start_url, max_pages=50):
    """Follow 'next' links from start_url. Returns (rows, pages_fetched)."""
    rows, url, pages = [], start_url, 0
    while url and pages < max_pages:
        soup = get_soup(url)
        rows.extend(parse_card(c) for c in soup.select("li.product-card"))
        pages += 1
        nxt = soup.select_one("nav.pagination a.next")
        url = urljoin(url, nxt["href"]) if nxt else None
        time.sleep(DELAY)
    return rows, pages

6.2 · Common mistakes

Read the type in the message

  • 'NoneType' object has no attribute: your search found nothing
  • ResultSet object has no attribute: you have a list
  • class= instead of class_=: a SyntaxError
  • A relative href requested as is: MissingSchema; use urljoin

Five you will meet

  • Orphaned browsers: no finally
