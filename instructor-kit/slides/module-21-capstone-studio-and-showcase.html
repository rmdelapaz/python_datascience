The Pinecrest Report

Frame · the rubric

Six rows, four levels

  • Question · Data handling · Analysis correctness
  • Visuals · Communication · Reproducibility
  • Proficient in all six is a successful capstone
  • An honest "no clear difference" scores as well as a discovery
Frame · the strong sentence

Five parts in every claim

  • The estimate for each group
  • The difference
  • Its 95% confidence interval
  • The test and its p-value
  • The effect size
EXAMPLE 25.8% vs 23.4%: 2.4 points (95% CI 1.9 to 2.9; Welch p < 0.001; d = 0.93)

Common mistakes

Five that produce no error

  • An unfair comparison
  • A merge that multiplies rows
  • Stale state: it only runs in your kernel
  • Searching until something is significant
  • A report that narrates the journey

Studio 2 · the figure

The Module 3 standard

  • A title that states the finding, not the topic
  • Axes labeled, with units
  • Color for a reason: one accent against gray is often enough
  • Error bars identified in the caption
  • Saved from code at a stated size: savefig("figure_1.png", dpi=150)
