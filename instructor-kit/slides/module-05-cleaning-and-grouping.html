Cleaning Data

Audit, fix one thing, check. Then prove it.

2.3 · Why it matters

Every chart, average and model inherits what is wrong with its table

  • Totals stored as text: pandas refuses to average them
  • Force the conversion carelessly and one row says $55,690 where the customer paid $556.90
  • Neither result announces itself as wrong
  • The raw file is read-only. Every fix is a line of code, so the job can be rerun and reviewed
2.3 · Mental model

The gear repair bench

  • Inspect the whole tent. Write down every problem before fixing any
  • Repair one thing at a time, structural damage first
  • Check each repair before starting the next
  • Some stains do not come out: note them on the tag, do not paint over them
SAY IT structure → text → numbers → dates → missing values

2.3 · Code

Audit by counting, not by scrolling

def audit(df):
    """One row per column: dtype, missing values, distinct values."""
    return pd.DataFrame({"dtype": df.dtypes.astype(str),
                         "missing": df.isna().sum(), "distinct": df.nunique()})

print(audit(raw).loc[["Store", "Status", "Payment Method"]])
               dtype  missing  distinct
Store            str        1        31
Status           str        1        15
Payment Method   str      409         7
TEST Five stores, three statuses, four payment methods. The file says 31, 15 and 7.

2.4

GroupBy Operations

Every question that starts with 'for each...'.

2.4 · Why it matters

Many rows in, one row per something out

  • A manager wants five lines: one per store
  • Marketing wants one line per customer. Finance wants one line per month
  • The same pattern is a spreadsheet pivot table, SQL GROUP BY, the bars of a bar chart
  • Today you take the one-liner from Lessons 0.1 and 2.3 apart and control every piece
2.4 · Mental model

Sorting the mail

  • Split: deal the receipts into piles, one pile per store
  • Apply: add up each pile
  • Combine: write the totals on one sheet, one line per pile
  • Before you type, ask: what shape do I want back?
SAY IT one row per group: agg · one value per row: transform · fewer rows: filter

2.4 · Common mistakes

Three mistakes everyone makes once

  1. summary["store"] after a groupby. KeyError: the key is the index. .reset_index().
  2. count for 'how many orders'. It skips gaps. Use size, and check the groups add up.
  3. Averaging the group averages. 182.66 is not 194.60. Go back to the rows.
WATCH Two of these three raise no error at all.
