7.3 · Why it matters

Three charts that ignore each other

  • You found the best day in the scatter
  • Then you hunted for it in the trend chart by eye
  • "These unusual points here: where are they there?"
  • Linked views answer that with one drag
7.3 · Mental model

A table in the middle of the room

  • Your data: one table in the middle of a room
  • Each chart: a window looking at it from a different side
  • Put stickers on thirty rows: every window shows them
  • Table = ColumnDataSource. Windows = plots. Stickers = a selection

7.4

Dashboards with Streamlit

The controls run your pandas.

7.4 · Why it matters

The ceiling of an HTML file

  • Everything it shows was computed before you saved it
  • "Can I pick my own date range and get the totals?"
  • "Can I download just those rows?"
  • For that, Python must be running while the reader uses the page
7.4 · Mental model

A spreadsheet that recalculates

  • An input cell at the top, formulas below
  • Change the input: every formula recalculates
  • The sheet is your script
  • Any widget change: the whole script runs again, top to bottom
BOARD the whole script reruns
7.4 · Code

hello.py: an app is a script

import pandas as pd
import streamlit as st

st.title("Pinecrest store sales")
sales = pd.read_csv("data/daily_sales.csv", parse_dates=["date"])
store = st.selectbox("Store", ["Boise", "Bend", "Flagstaff", "Asheville"])
one = sales[sales["store"] == store]
st.metric("Total revenue", f"${one['revenue'].sum():,.0f}")
st.line_chart(one, x="date", y="revenue")
st.write("The five best days:")
best = one.nlargest(5, "revenue")[["date", "visitors", "revenue"]]
st.dataframe(best, hide_index=True)
RUN streamlit run hello.py from the course folder. Not python hello.py. Stop with Ctrl+C.

7.4 · Code

Keys, and a reset in a callback

def reset():
    st.session_state["stores"] = STORES
    st.session_state["min_revenue"] = 0

if "stores" not in st.session_state:        # first run of this session
    reset()
st.multiselect("Stores", STORES, key="stores")
st.slider("Minimum daily revenue ($)", 0, 20000, step=1000, key="min_revenue")
st.button("Reset filters", on_click=reset)
RULE Change a widget's value only in a callback: it runs before the rerun.
7.4 · Code

Slow work once: st.cache_data

@st.cache_data
def load_sales(path):
    time.sleep(2)                          # stand-in for a slow file or query
    st.session_state["loads"] = st.session_state.get("loads", 0) + 1
    return pd.read_csv(path, parse_dates=["date"])

Three you will make this week

  • python app.py: warnings and no page. It is streamlit run
  • A variable that will not grow: it lives for one run
  • Setting a widget's value after it was drawn: use on_click=
  • Reading the CSV on every rerun: cache the load
