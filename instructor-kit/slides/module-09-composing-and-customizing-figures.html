3.2

Subplots and Composition

Grids, shared scales, named layouts, and the honest way to show two measures together.

3.2 · Mental model

Panels on a page

The pageThe Figure: one object, the thing that gets saved
Each panelAn Axes: you already know how to draw on one
Same chart per group?A grid: plt.subplots(rows, cols), and share the axes so sizes compare
A mix of charts?A layout: plt.subplot_mosaic, the biggest panel for the main point
WHY ax With several Axes there is no single "current chart".
3.2 · Code

A grid is an array

fig, axs = plt.subplots(2, 2, figsize=(9, 5.5), layout="constrained")
print(type(axs).__name__, axs.shape, type(axs[0, 1]).__name__, len(fig.axes))
plt.close(fig)
ndarray (2, 2) Axes 4
ASK Which panel is axs[0, 1]? Row 0, column 1: top right.

fig, axs = plt.subplots(2, 2, layout="constrained")

RULE plt.title writes on the last Axes created. Use ax.set_title.

3.2 · Common mistakes

Three ways this goes wrong

  • axs.plot(...) → AttributeError: 'numpy.ndarray' object has no attribute 'plot'
  • axs[0, 1] on a one-row grid → IndexError: too many indices
  • Comparing heights across panels that do not share a scale: no error, a wrong conclusion
  • Leftover empty panels: remove them with ax.remove()
HABIT Size or shape? Share, or say so.

3.3

Customizing Plots

From correct to clear: a title that states the finding, readable axes, color with a purpose.

3.3 · Mental model

You are the editor

  • Matplotlib's default is a first draft: accurate, complete, no story
  • The editor writes the headline
  • Cuts what does not serve the story
  • Makes the eye land on the important part first
TEST Does this edit help the reader get the point faster?
3.3 · First draft

What would a stranger struggle with?

  • A title with no point
  • Four equally loud colors
  • A legend to look up four times
  • 150000 of what? The year on every label
3.3 · Check first

The story, in numbers

jan, dec = monthly.iloc[0], monthly.iloc[-1]
print("Jan 2024, smallest first:", list(jan.sort_values().index))
print("Dec 2025, smallest first:", list(dec.sort_values().index))
Jan 2024, smallest first: ['Flagstaff', 'Asheville', 'Bend', 'Boise']
Dec 2025, smallest first: ['Asheville', 'Bend', 'Flagstaff', 'Boise']
RULE A finding title is a claim. Check it with a number before you write it.

3.3 · Code

Locators and formatters

thousands = lambda x, pos: f"${x / 1000:,.0f}K"
fig, ax = plt.subplots()
ax.plot(monthly.index, monthly["Boise"])
ax.yaxis.set_major_formatter(FuncFormatter(thousands))          # 250000 -> $250K
ax.xaxis.set_major_locator(mdates.MonthLocator(bymonth=[1, 7]))  # every Jan and Jul
ax.xaxis.set_major_formatter(mdates.DateFormatter("%b %Y"))      # Jul 2024
fig.canvas.draw()
texts = lambda labels: [t.get_text() for t in labels]
print(texts(ax.get_yticklabels())[1:5], texts(ax.get_xticklabels())[:3])
['$200K', '$225K', '$250K', '$275K'] ['Jan 2024', 'Jul 2024', 'Jan 2025']
WATCH A format string needs the name x: "${x:,.0f}".
3.3 · Color

Give color one job

HighlightGray plus one accent: the story and its context
CategoriesQualitative, such as Okabe-Ito: a few unordered groups
How muchSequential, such as viridis: low to high
Above or belowDiverging, such as RdBu, centered on the midpoint
ALWAYS A second cue besides color. No red against green as the only difference.

3.3 · Code

A bar chart that lies with a straight face

totals = daily[daily["date"].dt.year == 2025].groupby("store")["revenue"].sum()
boise_t, ash_t = totals["Boise"], totals["Asheville"]
print("True ratio, Boise to Asheville:", round(boise_t / ash_t, 1))
cut = 1_500_000
drawn = (boise_t - cut) / (ash_t - cut)
print("Ratio of the bar heights drawn:", round(drawn, 1))
True ratio, Boise to Asheville: 1.9
Ratio of the bar heights drawn: 4.5
RULE Bars start at zero. A bar's length is its value.

3.3 · Common mistakes

Three ways this goes wrong

  • "${:,.0f}" (no x) → IndexError: tuple index out of range, at draw time
  • A headline that claims more than the bars show
  • Decorating: more colors, a kept legend, a cut bar axis, red against green
  • Three ticks, two labels → ValueError: ... FixedLocator locations (3) ... labels (2)
HABIT Did I check the headline with a number?
