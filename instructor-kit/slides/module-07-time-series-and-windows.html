Every question here is about order in time

  • Is Asheville's revenue falling?

2.7 · Mental model

A ruler, not a list of labels

  1. Parse the dates: text has no order and no distances
  2. Put them in the index
  3. Complete the calendar with asfreq
  4. Decide what each gap means
  5. Only then resample, shift, compare
RULE Most time series mistakes come from skipping step 3.

2.7 · Common mistakes

Three ways this goes wrong

  • Text or no date index: Can only use .dt accessor... / Only valid with DatetimeIndex... → parse_dates, then index or on=
  • A total without its count: no error. A gap reads as a bad month
  • One fill for every gap: fillna(0) invents closed days; interpolate() invents Christmas sales
  • Old alias "M" → ValueError: use "ME", "QE", "YE", "h"
HABIT Count beside every sum.

2.8

Window Functions

A summary for every row: moving averages, running totals, ranks, and never peeking at the future.

2.8 · Why it matters

Monthly totals cost you the detail

groupby().agg() / resample()One row per group. "What was July's total?"
Window functionOne row per input row. "What was the average of the last 7 days, on each day?"
Closest relativegroupby().transform(), which also returns one value per row
GOAL Keep all 731 days, and give each one some context.
2.8 · Mental model

Looking out of a train window

rolling(7)The pane of glass: always the last 7 days, sliding one day at a time
expanding()A camera filming since the first station: everything so far
ewm(span=7)Your memory of the trip: recent days vivid, early ones faded
WHY 7 A 7-day window always holds one of each weekday, so the weekly zigzag cancels.

A leak flatters the result

tests = {"3-day, centered (leaks)": boise.rolling(3, center=True).mean(),

2.8 · Common mistakes

Three ways this goes wrong

  • Rolling across groups on a long table: no error, no meaning → sort, group, transform
  • min_periods=1 to make the NaN go away: averages built on one day
  • A baseline that contains the day it judges (or center=True) → shift(1) first
  • Assigning groupby().rolling() straight back → TypeError: incompatible index
