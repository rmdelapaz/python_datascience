2.1

DataFrames and Series

A column with labels, and a table of columns that share them.

2.1 · Why it matters

Every remaining lesson starts or ends with a DataFrame

  • An array holds one type. A product has a name, a price, a count and a date
  • An array knows values by position. Position 5 means nothing until you remember what you put there
  • pandas gives every value a label and lets columns of different types sit side by side
  • Six moves you will type hundreds of times: look, pick columns, pick rows, add a column, sort, count
2.1 · Mental model

The labeled shelf

  • A Series is one shelf of bins. Every bin has a label on the front
  • A DataFrame is the shelving unit: the same label runs across every shelf
  • Pull the label TNT-1002: name, price and rating come out together
  • Underneath, each shelf is still a NumPy array with one dtype
SAY IT Values + index + name. Labels travel with their values.

2.1 · Common mistakes

Three mistakes everyone makes once

  1. and between masks. ValueError: truth value of a Series is ambiguous. Use &.
  2. df[mask]["col"] = 0. A warning, and nothing changes. Use df.loc[mask, "col"] = 0.
  3. .loc[0] on a table indexed by SKU. KeyError: 0. Positions need .iloc.
WATCH Read the LAST line of the error first.

2.2

Loading Data

Brief the reader, check the translation, save what you trust.

2.2 · Why it matters

A surprising share of wrong answers begin at the load

  • A date that loads as text cannot be grouped by month
  • An id that loads as a decimal will not match the same id in another table
  • A header on row 4 turns the whole sheet into nonsense, with no error
  • Analysts load raw files once, get every type right, and save a snapshot
2.2 · Mental model

The interpreter at the border

  • A file is a message in another language. 2024-01-01 is only characters
  • read_csv is an interpreter who makes a reasonable guess
  • Options are the briefing: this is a date, n/a means missing, skip two lines
  • Then check the translation: shape, dtypes, head() after every load
SAY IT file → reader + options → DataFrame → check → analyze → writer

2.2 · Common mistakes

Three mistakes everyone makes once

  1. The file is not where Python is looking. FileNotFoundError. Print Path.cwd().
  2. Trusting a load because it ran. Look at shape and dtypes after every load.
  3. pd.read_json on a nested file. Use json.load, then pd.json_normalize.
WATCH The dangerous mistakes today raise no error at all.
