4.4

Correlation Analysis

Plot first. Then ask how the data came to be.

4.4 · Mental model

Two dancers

  • Stepping forward and back together: positively correlated
  • One forward whenever the other steps back: negatively
  • Each with no regard for the other: uncorrelated
  • Correlation measures how well they are in step
  • It says nothing about why: one may lead, or both follow the music
WHY Read a scatter plot for direction, form and strength. Then measure.
4.4 · Code

What r is made of

zx = (x - x.mean()) / x.std()
zy = (y - y.mean()) / y.std()
print("by hand        :", round((zx * zy).sum() / (len(x) - 1), 4))
print("pandas .corr() :", round(x.corr(y), 4))
print("scipy pearsonr :", round(stats.pearsonr(x, y).statistic, 4))
by hand        : 0.9435
pandas .corr() : 0.9435
scipy pearsonr : 0.9435
WHY No units. Symmetric. Not robust. Not a slope, not a percentage.

4.4 · The confounder

Expected demand drives both

  • Staff are scheduled in advance from expected demand
  • The calendar (weekday, season, promotions) drives expected demand
  • Expected demand brings more staff and more visitors
  • Visitors produce revenue
  • Staff to revenue directly: unknown
WHY A confounder can create a strong correlation between two things that do not affect each other.

4.4 · The verdict

Three checks agree

  • Staff and revenue, all days pooled: 0.88
  • Same store, month, weekday and promotion status: 0.14
  • Holding visitors constant (partial correlation): 0.07
  • Staff and spend per visitor: 0.03
  • Not proof of no effect: to rule a story in, run an experiment
WHY Nearly all of the 0.88 is the calendar acting on both.
4.4 · Before you report

Five explanations for any correlation

  • A causes B
  • B causes A (the arrow points the other way)
  • A confounder causes both
  • Selection: how rows got into the data
  • Chance: look at enough pairs and some correlate
WHY Correlation is where an investigation starts, not where it ends.

4.4 · Common mistakes

Clean-looking numbers that mislead

  • r read as a slope ("94 cents") or a percentage ("94% related")
  • r = 0 read as "no relationship": a perfect curve scores 0
  • np.corrcoef with missing values: nan
  • Pooling groups that differ in level
WATCH Think in r squared: r = 0.5 accounts for 25% of the variance.

4.5

Hypothesis Testing

Assume nothing is going on. How surprising are the data?

4.5 · Mental model

The courtroom

  • Start from "innocent": the null hypothesis, nothing going on
  • Ask whether the evidence would be surprising if that were true
  • Very surprising: reject the null
  • Not surprising: fail to reject. "Not guilty" is not "proven innocent"
WHY The question: Asheville's recommend score is 0.36 points lower. Could that be luck?
4.5 · Code

Build chance yourself: shuffle the labels

rng = np.random.default_rng(42)
pooled = np.concatenate([asheville, others])
n_ash = len(asheville)
shuffled_diffs = np.empty(10_000)
for i in range(10_000):
    shuffled = rng.permutation(pooled)
    shuffled_diffs[i] = shuffled[:n_ash].mean() - shuffled[n_ash:].mean()

print(shuffled_diffs[:5].round(3))
print(f"typical chance gap (SD): {shuffled_diffs.std():.3f}")
[-0.03   0.034 -0.216  0.277  0.124]
typical chance gap (SD): 0.165
WHY Each number: a gap between two groups that cannot truly differ.
4.5 · Code

Count: the p-value

as_extreme = np.abs(shuffled_diffs) >= abs(observed)
print(as_extreme.sum(), "of 10,000 shuffles gave a gap at least this large")
print(f"p-value = {as_extreme.mean():.3f}")
300 of 10,000 shuffles gave a gap at least this large
p-value = 0.030
WHY If the store made no difference, a gap this large turns up about 3% of the time.
4.5 · Read it right

What a p-value is not

  • Not "a 3% chance the null hypothesis is true"
  • Not "a 97% chance Asheville is worse"
  • Not a measure of size or importance
  • A large p is not "the same": it is "not detected"
  • 0.049 and 0.051 are the same evidence
RULE p = the probability, if the null were true, of a result at least this extreme.
4.5 · Code

The shortcut: Welch's t-test

res = stats.ttest_ind(asheville, others, equal_var=False)
ci = res.confidence_interval(confidence_level=0.95)
print(f"t = {res.statistic:.2f}, df = {res.df:.0f}, p = {res.pvalue:.3f}")
print(f"95% CI for the difference: {ci.low:.2f} to {ci.high:.2f}")
t = -2.17, df = 305, p = 0.030
95% CI for the difference: -0.68 to -0.03
WHY Always equal_var=False. The interval excludes 0: the same fact as p below 0.05.
4.5 · Code

How big? Cohen's d

def cohens_d(x, y):
    nx, ny = len(x), len(y)
    pooled = (((nx - 1) * np.var(x, ddof=1) + (ny - 1) * np.var(y, ddof=1))
              / (nx + ny - 2))
    return (np.mean(x) - np.mean(y)) / np.sqrt(pooled)

print(f"Cohen's d = {cohens_d(asheville, others):.2f}")
Cohen's d = -0.17
WHY 0.2 small, 0.5 medium, 0.8 large. A p-value never travels alone.

Same days, two stores: pair them

daily = pd.read_csv("data/daily_sales.csv", parse_dates=["date"])

4.5 · Choosing

Which test?

  1. Outcome is a category: chi-square on a crosstab table
  2. A rating or rank: Mann-Whitney U
  3. One group against a target: one-sample t
  4. The same units measured twice: paired t
  5. Otherwise, two independent groups: Welch t
WHY Every test assumes independent observations.
4.5 · Code

False alarms, watched

rng = np.random.default_rng(42)
pool = in_store["recommend"].dropna().to_numpy()
p_null = np.array([
    stats.ttest_ind(rng.choice(pool, 197), rng.choice(pool, 752),
                    equal_var=False).pvalue
    for _ in range(2_000)])
share = (p_null < 0.05).mean()
print(f"{share:.1%} of 2,000 tests of a true null were significant")
5.3% of 2,000 tests of a true null were significant
WHY When nothing is going on, one test in twenty still rings the alarm.
4.5 · Code

Power: the chance of catching a real effect

from statsmodels.stats.power import TTestIndPower

for n in (50, 100, 200, 400, 800):
    power = TTestIndPower().power(effect_size=0.2, nobs1=n, alpha=0.05)
    print(f"n = {n:>3} per group: power {power:.2f}")
n =  50 per group: power 0.17
n = 100 per group: power 0.29
n = 200 per group: power 0.51
n = 400 per group: power 0.81
n = 800 per group: power 0.98
WHY With 50 per group a small real effect is missed five times out of six.
4.5 · Common mistakes

Five to catch

  • A missing value makes the p-value nan: .dropna() first
  • Forgetting equal_var=False
  • "Not significant" written as "no difference"
  • Thirty tests, only the winners reported: count them, use Holm
  • Choosing a one-sided test after seeing the data
WATCH Report: comparison and n · estimate · 95% CI · test and p · effect size · caveats.
