7.1

Statistical Graphics with Seaborn

Name the columns. Seaborn groups, computes and draws.

7.1 · Why it matters

Exploration is a loop

  • Look, wonder, slice another way, look again
  • If each slice costs ten lines, you look at fewer slices
  • Seaborn makes "the same chart, split by store" a one-word change
  • It also computes means and intervals: you must know which
7.1 · Mental model

The drafting assistant

  • Matplotlib: a drawing table with excellent pens
  • Seaborn: an assistant at the same table who takes orders by column name
  • It splits groups, picks colors, computes averages, writes the legend
  • When it is done, you can still pick up a pen
PATTERN sns.something(data=table, x="col", y="col", hue="col")

7.1 · errorbar=

Spread or uncertainty?

  • ("ci", 95) (default): 95% confidence interval for the mean. Uncertainty
  • "se": one standard error. Uncertainty
  • "sd": one standard deviation. Spread
  • ("pi", 50): the middle 50% of the data. Spread
  • Uncertainty shrinks with more data. Spread does not
HABIT Say in the caption what the bars are. Pass seed= so they repeat.

7.1 · Common mistake

No error, wrong order

ages = ["18-24", "25-34", "35-44", "45-54", "55-64", "65+"]
fig, ax = plt.subplots()
sns.countplot(data=survey, x="age_group", ax=ax)
print([label.get_text() for label in ax.get_xticklabels()])
sns.countplot(data=survey, x="age_group", order=ages, ax=ax)
['65+', '18-24', '25-34', '45-54', '35-44', '55-64']
FIX Categories are drawn in first-seen order. Pass order=, hue_order=, col_order=.

Interactive Charts with Plotly

A chart your reader can question.

7.2 · Why it matters

The reader's first move is a follow-up

  • "What happened in that spike?"
  • "What is the exact figure for June?"
  • "Can I see only Flagstaff?"
  • With a picture, each one is an email back to you
7.2 · Mental model

The wall map and the map app

  • Static chart: a printed map. Composed, fixed, the same for everyone
  • Interactive chart: a map app. Zoom, tap a pin, switch layers
  • You still choose what is on the map and the default view
  • Python builds a description. A browser draws it
BOARD figure = data (traces) + layout

7.2 · Code

px.bar does not aggregate

wrong = px.bar(sales, x="store", y="revenue")
print(len(wrong.data[0].x), "bar segments")
by_store = sales.groupby("store", as_index=False)["revenue"].mean()
right = px.bar(by_store, x="store", y="revenue", text_auto=",.0f")
print(len(right.data[0].x), "bars")
2903 bar segments
4 bars
RULE Seaborn averaged for you. Plotly Express will not. Aggregate first.
7.2 · Code

A hover that answers the next question

sales["day"] = sales["date"].dt.strftime("%a %b %d, %Y")
fig = px.scatter(sales, x="visitors", y="revenue", color="store", hover_name="day",
                 hover_data={"revenue": ":$,.0f", "visitors": ":,"})
best = sales.loc[sales["revenue"].idxmax()]
print(best["day"], "|", best["store"], "|", f"${best['revenue']:,.0f}")
Sat Aug 31, 2024 | Boise | $27,677
FORMAT After the colon: $ dollars, , thousands, .0f no decimals, .1% percent.
