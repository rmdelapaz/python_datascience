📚 About This Course

Data science is not a list of libraries. It is a way of working: ask a clear question, get the data, clean it, explore it, test what you think you see, and show what you found. This course teaches the Python tools for each of those steps, in the order you would use them on a real project.

  1. Ask
  2. Load
  3. Clean
  4. Explore
  5. Test
  6. Show

🎯 What You Will Be Able to Do

  • Compute with arrays in NumPy instead of writing loops
  • Load, clean, reshape, combine and summarize tables with pandas
  • Build clear charts with Matplotlib and seaborn, and interactive ones with Plotly and Bokeh
  • Describe data honestly and run a hypothesis test or an A/B test without fooling yourself
  • Query a database with SQL from Python, including joins, window functions and indexes
  • Collect data from web pages and APIs politely and safely
  • Turn an analysis into a small dashboard, and write up findings in a capstone report

✅ Prerequisites

You should be comfortable writing small Python programs: variables, if, loops, functions, lists and dictionaries, reading and writing files, and basic classes. You do not need any statistics or prior data experience.

If that list sounds unfamiliar, start with the Intro and Intermediate Python courses at Ray's House of Fun, then come back.

You will need: a Windows, macOS or Linux computer on which you can install software, Python 3.12 or newer, and about 2 GB of free disk space. Lesson 0.1 walks you through the whole setup.

💡 How the Course Works

  1. Go in order. Lessons assume the ones before them. Module 0 sets up your computer, and everything after depends on it.
  2. Type along. Every code block shows its real output underneath. Run each one yourself and compare. When yours differs, you have found something worth understanding.
  3. Build the project. Each lesson has one guided project on the course data, with a complete solution and a checklist.
  4. Do the exercises, then the quiz. Three to five exercises with hidden solutions, and five quick questions that give you a hint when you miss.
  5. Write in your journal. Five minutes at the end of each lesson. It is the cheapest way to make learning stick.

Each lesson shows an honest time estimate that includes the typing, the project and the quiz. Most take between an hour and a quarter and just under two hours.

Taking or teaching it in a classroom? The instructor-led syllabus lays the course out as 21 three-hour sessions.

🏔️ The Data: Pinecrest Outfitters

Every lesson uses the same dataset: two years of records from Pinecrest Outfitters, an outdoor-gear retailer with an online shop and stores in Boise, Bend, Flagstaff and Asheville. The company is fictional, and so is every customer, product and number. The data was written for this course to behave like the real thing, flaws included.

  • Products, customers, orders and order lines as CSV files and as a SQLite database
  • A deliberately messy export for the cleaning lesson
  • Daily store sales and weather for time series work
  • A customer survey and a checkout-page experiment for statistics
  • Nested website sessions in JSON and an Excel workbook
⬇️ Download the data (2.3 MB zip) requirements.txt

Unzip it inside your project folder so that you have a data folder next to your notebooks. The zip includes a README describing every file and column. For the web lessons there is also a practice shop to scrape and a small practice API that runs on your own computer, so you never have to point your code at a real site while you learn. To work on the web lessons offline, download pinecrest-practice-site.zip (0.4 MB), unzip it in your project folder and serve it with python -m http.server 8001; Lesson 6.1 shows how.

📖 Course Modules

0 🧰 Start Here 1 lesson · 1 h 30 min

Set up Python, a virtual environment and Jupyter, download the course data, and run your first analysis.

  • 0.1 Your Data Science Toolkit 90 min Install Python, build a virtual environment, meet notebooks and scripts, and run a first analysis on the Pinecrest data.

1 🔢 NumPy Fundamentals 5 lessons · 6 h 55 min

The array: the data structure underneath pandas, Matplotlib, SciPy and nearly everything else in this course.

  • 1.1 Arrays vs Lists 80 min Why NumPy arrays are smaller and faster than lists, and how to create, inspect, index and copy them.
  • 1.2 Vectorized Operations 85 min Replace loops with whole-array arithmetic, comparisons, boolean masks and aggregations.
  • 1.3 Broadcasting 75 min How NumPy combines arrays of different shapes, and how to read a shape error.
  • 1.4 Random Number Generation 85 min Seeded generators, sampling and simulation with numpy.random.default_rng.
  • 1.5 Linear Algebra Essentials 90 min Vectors, matrices, dot products and solving linear systems with numpy.linalg.

2 🐼 Pandas 9 lessons · 13 h 40 min

Load, clean, reshape, combine and summarize real tables of data.

  • 2.1 DataFrames and Series 90 min The two core pandas objects: creating, selecting, filtering and adding columns.
  • 2.2 Loading Data 85 min Read CSV, Excel, JSON and SQL into DataFrames with the right types from the start.
  • 2.3 Cleaning Data 100 min Fix missing values, duplicates, inconsistent labels, bad dates and text-as-numbers in a messy export.
  • 2.4 GroupBy Operations 90 min Split, apply, combine: summarize by store, category and customer.
  • 2.5 Merging and Joining 95 min Combine tables on keys, choose the right join, and catch rows that do not match.
  • 2.6 Pivot Tables and Reshaping 85 min Pivot, melt, stack and crosstab to move between long and wide data.
  • 2.7 Time Series 90 min Datetime indexes, resampling, and handling gaps in daily data.
  • 2.8 Window Functions 90 min Rolling, expanding and exponentially weighted calculations, ranks and shifts.
  • 2.9 Feature Engineering Basics 95 min Turn raw columns into useful features: bins, dates, ratios, encodings and customer summaries.

3 📈 Visualization with Matplotlib 4 lessons · 5 h 40 min

Build clear charts with the object-oriented Matplotlib interface.

  • 3.1 Line, Scatter and Bar Charts 90 min The three workhorse charts and when each one is the right choice.
  • 3.2 Subplots and Composition 85 min Lay out several axes in one figure and make them read as a whole.
  • 3.3 Customizing Plots 90 min Titles, labels, ticks, colors, annotations and styles that make a chart say one thing clearly.
  • 3.4 Saving Figures 75 min Export figures at the right size, resolution and format for reports, slides and the web.

4 📐 Statistics for Data Analysis 7 lessons · 11 h 30 min

Describe data honestly, quantify uncertainty, and test claims without fooling yourself.

  • 4.1 Descriptive Statistics I: Center and Spread 85 min Mean, median, mode, variance, standard deviation and when each one misleads.
  • 4.2 Descriptive Statistics II: Shape, Position and Outliers 90 min Skew, percentiles, z-scores, outlier rules and summaries by group.
  • 4.3 Probability Distributions 100 min Normal, binomial, Poisson and friends with scipy.stats, plus sampling distributions.
  • 4.4 Correlation Analysis 95 min Pearson and Spearman, what correlation hides, and a confound hiding in the store data.
  • 4.5 Hypothesis Testing 110 min Null hypotheses, p-values, effect sizes, t-tests, chi-square and their assumptions.
  • 4.6 A/B Testing 100 min Plan a sample size, analyze the checkout experiment, and avoid peeking.
  • 4.7 An EDA Workflow 110 min A repeatable routine for exploring a new dataset from first look to written findings.

5 🗄️ SQL and Databases 5 lessons · 8 h 25 min

Query a relational database from Python, then meet a document database.

  • 5.1 Database Connections 100 min Connect to SQLite with sqlite3 and SQLAlchemy, run safe parameterized queries, and load results into pandas.
  • 5.2 Complex Queries 110 min Joins, subqueries, CTEs (including a recursive one) and CASE expressions.
  • 5.3 SQL Window Functions 100 min Running totals, rankings and comparisons to previous rows with OVER.
  • 5.4 Query Optimization 100 min Read EXPLAIN QUERY PLAN, add an index, and measure the difference.
  • 5.5 NoSQL with MongoDB 95 min Documents, queries and aggregation pipelines with PyMongo on nested session data.

6 🌐 Getting Data from the Web 5 lessons · 7 h 40 min

Collect data politely from web pages and APIs.

  • 6.1 HTTP with Requests 90 min Requests, responses, status codes, headers, timeouts and robots.txt.
  • 6.2 Parsing HTML with Beautiful Soup 95 min Select elements, follow pagination and turn a practice catalog into a DataFrame.
  • 6.3 Dynamic Pages with Selenium 90 min Drive a real browser, wait for JavaScript content, and know when you do not need to.
  • 6.4 API Authentication 90 min API keys, bearer tokens, token expiry and keeping secrets out of your code.
  • 6.5 Rate Limiting and Retries 95 min Respect 429 and Retry-After, back off, cache, and be a polite client.

7 🎨 Interactive Visualization and Dashboards 4 lessons · 6 h 05 min

Statistical graphics, interactive charts and a small data app.

  • 7.1 Statistical Graphics with Seaborn 90 min Distributions, relationships and categories with seaborn's figure-level and axes-level functions.
  • 7.2 Interactive Charts with Plotly 90 min Hover, zoom and filter with Plotly Express and graph objects.
  • 7.3 Interactive Charts with Bokeh 90 min Linked plots, tools and widgets in the browser with Bokeh.
  • 7.4 Dashboards with Streamlit 95 min Turn an analysis into a small interactive web app.

8 🏔️ Capstone 1 lesson · 7 h

One end-to-end analysis, from question to written findings.

  • 8.1 The Pinecrest Report 420 min Question, data, cleaning, exploration, a test, charts and a short written report, with a rubric.
